# هُويّة | HAWIYA

موقع عربي لاستوديو تصميم هويات بصرية، فيه **مولد هوية** يشتغل مباشرة: تكتب اسم المشروع ونشاطه ونمط الهوية، ويقترح لك الموقع لوحة ألوان وشعار مبدئي وخطوط مناسبة ووصف للهوية.

> 🇬🇧 [English version](README.md)

## ✨ المميزات

- الأقسام: الرئيسية، الخدمات، الباقات، مولد الهوية، آراء العملاء، تواصل
- **مولد الهوية**: ٤ ألوان، شعار مبدئي (SVG)، خط للعناوين وخط للنصوص، ووصف للهوية حسب النشاط والنمط
- ثيم كحلي وبرتقالي متدرج مع زر للوضع الفاتح (يتذكر اختيار الزائر)
- متجاوب مع الجوال، قائمة جوال، تمييز القسم الحالي، وحركات ظهور عند التمرير
- تحقق من الحقول في نموذج المولد ونموذج التواصل
- بدون مكتبات أو أدوات بناء

## 🚀 التشغيل

```bash
npm start   # تشغيل الموقع محلياً
npm test    # تشغيل اختبارات محرك الهوية
```

أو افتح `index.html` مباشرة في المتصفح.

## 🧠 طريقة عمل المولد

الملف `js/core/identity-engine.js` يحوّل اسم المشروع والنشاط والنمط إلى رقم ثابت، فنفس المدخلات تعطي نفس الهوية دائماً.

- **النشاط** يحدد درجة اللون الأساسية (مثلاً المطاعم ← برتقالي دافئ، التقنية ← أزرق)
- **النمط** يحدد التشبع والسطوع والخطوط وشكل الشعار (عصري، فاخر، بسيط، مرح، كلاسيكي)

## ✏️ تغيير اسم العلامة

الاسم مكتوب في مكان واحد فقط: `js/config.js`

## 📮 نموذج التواصل

النموذج يتحقق من البيانات ويعرض رسالة تأكيد. لاستلام الرسائل فعلياً، اربطه بخدمة نماذج (مثل Formspree أو Web3Forms) في `js/modules/contact-form.js`.
